# Amazon Prime Video Analytics Dashboard

## About Project
This Power BI project analyzes Amazon Prime Video content to understand
movies, TV shows, genres, countries, and release trends.

## Tools Used
- Power BI
- DAX
- Power Query

## KPIs Covered
- Total Titles
- Movies vs TV Shows
- Genre Distribution
- Country-wise Content
- Release Year Trends

## Key Insights
- Movies contribute around 65% of total content.
- Drama and Comedy are the most common genres.
- Majority of content was released after 2015.

## Purpose
This dashboard is created as part of my Power BI portfolio
to demonstrate data analysis and visualization skills.
