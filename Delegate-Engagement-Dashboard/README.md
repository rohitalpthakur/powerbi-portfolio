# Delegate Engagement & Networking Insights Dashboard

## About Project
This Power BI dashboard analyzes delegate attendance, engagement,
networking behavior, and sponsor performance for corporate events.

## KPIs Covered
- Registered vs Attended Participants
- Attendance Rate %
- Engagement Score
- Meetings Booked
- Average Networking Time
- Sponsor-wise Leads

## Key Insights
- High attendance rate (~97%) indicates strong event participation
- Certain sponsors generate significantly higher delegate leads
- CXO and Manager level delegates show higher networking engagement

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization
